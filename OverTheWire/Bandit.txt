File Type (1st Character)
- : Regular file (text, script, image, etc.)
d : Directory (folder)
l : Symbolic link (shortcut)

Permission Groups (Next 9 Characters) -> Format = --- to rwx (Read, Write, Execute)
Owner (User): The person who owns the file.
Group: Other users who belong to the file's assigned group.
Others (World): Absolutely everyone else on the system.

-rwxr-x---         1               bandit22    bandit21         130            Sep 26 21:53   [filename]
[Perms]   [Links cnt](Hard link)    [Owner]    [Group]   [Bytes](file size)   [Last Modified] [Name]

Link Count : The number of hard links pointing to this file. For a regular file, this is almost always 1 (Me call myself) it will increase when you add subfolder or add something that link it with the other (same file by copying [ln og_file new_file])

Hard Link: Think of it as a clone. It points directly to the physical data on the disk. If you delete the original file, the hard link still works and the data is kept safe.

Soft Link (Symlink): Think of it as a shortcut. It only points to the location (path) of the original file. If you delete the original file, the soft link breaks and becomes completely useless.
